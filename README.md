# Románico en Cantabria - PWA de Turismo Cultural

¡Bienvenido a la guía definitiva del **Románico en Cantabria**! Esta aplicación es una Progressive Web App (PWA) diseñada para amantes del arte medieval, historiadores y turistas que desean explorar el rico patrimonio arquitectónico de Cantabria.

## 🏰 Características Principales
- **Colección de Iglesias**: Explora más de 100 puntos de interés del románico cántabro.
- **Mapa Interactivo**: Ubicación exacta de colegiatas, iglesias y monumentos.
- **Rutas Personalizadas**: Generador de itinerarios para un día de turismo románico.
- **Agenda Cultural**: Eventos y noticias actualizadas sobre el patrimonio medieval.
- **Comunidad**: Comparte tus propias fotografías y valora tus lugares favoritos.

## 🔍 Palabras Clave SEO
Para mejorar el posicionamiento de esta aplicación, se han integrado conceptos clave como:
- **Turismo Románico Cantabria**
- **Arte Medieval en el Norte de España**
- **Rutas de Senderismo Cultural**
- **Colegiata de Santillana del Mar**
- **Arquitectura Románica Cántabra**
- **Pueblos Mágicos de Cantabria**

## 🚀 Cómo empezar
Simplemente abre `index.html` en tu navegador o instala la PWA en tu dispositivo móvil para disfrutar de la experiencia completa offline.
